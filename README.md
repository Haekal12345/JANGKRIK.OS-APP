**Jangkrik.OS** adalah *Progressive Web App* (PWA) komprehensif yang dirancang khusus untuk mendigitalisasi operasional peternakan jangkrik (khususnya Jangkrik Alam). Sistem ini mengubah pencatatan manual menjadi ekosistem cerdas yang melacak siklus produksi, menjadwalkan panen, memantau kesehatan finansial, hingga memberikan rekomendasi bisnis melalui integrasi AI Asisten.

## ✨ Fitur Unggulan

### 📊 Dashboard Finansial & Visualisasi Data
Memantau performa peternakan dalam satu layar. Dilengkapi dengan ringkasan laba bersih, total penjualan/pengeluaran, volume panen, serta grafik interaktif yang memetakan tren pendapatan harian dan bulanan secara *real-time*.

## 🛠️ Tech Stack

Aplikasi ini dibangun menggunakan ekosistem pengembangan modern untuk memastikan performa yang cepat dan pengalaman pengguna yang mulus.

**Frontend Architecture:**
*   **Framework:** React.js
*   **Build Tool:** Vite (Super cepat dan optimal)
*   **PWA Integration:** Custom Service Workers (`sw.js`) & Web Manifest untuk kapabilitas instalasi *native*.

**Backend & Deployment:**
*   **Runtime/Environment:** Node.js
*   **Hosting/Deployment:** Vercel (Serverless deployment)

## 🚀 Instalasi Aplikasi (PWA Ready)

Aplikasi ini dapat diinstal langsung ke layar utama perangkat (HP/Desktop) Anda tanpa perlu mengunduh dari App Store/Play Store. Memori yang digunakan sangat kecil dengan performa maksimal.

- **📱 Android (Chrome):** Buka link aplikasi ➔ Ketuk notifikasi *Add to Home Screen* atau pilih *Install App* dari menu titik tiga (⋮).
- **🍏 iOS (Safari):** Buka link aplikasi ➔ Ketuk ikon *Share* di bawah layar ➔ Pilih *Add to Home Screen*.
- **💻 Desktop (Chrome/Edge):** Buka link aplikasi ➔ Klik ikon *Install* (monitor dengan panah bawah) di pojok kanan *Address Bar*.
